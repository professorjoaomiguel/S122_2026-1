## 🏛️ Arquitetura de Referência (M3F)
Nossa trilha segue o modelo de camadas para sistemas IoT:
1.  **Percepção (Edge):** ESP32, MicroPython e sensoriamento.
2.  **Transporte e Fog (Local):** Gateway Raspberry Pi, MQTT, Docker e InfluxDB.
3.  **Aplicação (Cloud):** Node-RED, Grafana e Dashboards interativos.

## 💡 Filosofia de Aprendizado
Este curso utiliza a **Filosofia de Aprendizado Ativo**:
- **Tutor IA:** O assistente (Gemini CLI) atuará como um tutor, guiando seu raciocínio sem entregar soluções imediatas.
- **Template vs Solution:** Você receberá arquivos de template com desafios (`# TODO`) e deverá preencher a **Reflexão Técnica** ao final de cada código.
- **Controle de Versão:** O uso do Git é parte integrante da disciplina.
